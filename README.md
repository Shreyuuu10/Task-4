## Retail Sales Analysis Dashboard

## Overview

This project presents an interactive Retail Sales Analysis Dashboard developed using Power BI. The dashboard provides insights into sales performance, profitability, customer behavior, and regional trends to support data-driven business decisions.

## Project Objectives
Analyze overall sales and profit performance
Identify top-performing product categories
Evaluate regional sales trends
Understand customer purchasing behavior
Monitor key business KPIs through interactive dashboards

| Attribute     | Details           |
| ------------- | ----------------- |
| Dataset Type  | Retail Sales Data |
| Format        | Excel (.xlsx)     |
| Records       | ~9,994            |
| Analysis Tool | Power BI          |

### Tools & Technologies
Power BI Desktop
Microsoft Excel
Power Query
DAX (Data Analysis Expressions)

### Data Preparation
The dataset was prepared using the following steps:

Data validation

Duplicate record verification
Data type formatting
Date standardization
Data transformation using Power Query
